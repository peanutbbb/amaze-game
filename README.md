# 🌑 AMAZE - Dark Maze Game

A dark-themed maze navigation game built with HTML5 Canvas and JavaScript.

## Play the Game

Open `index.html` in any modern web browser, or host it on GitHub Pages.

## How to Play

- Use **Arrow Keys** or **WASD** to move your glowing orb through the maze
- On mobile: **Swipe** in the direction you want to move
- Navigate through the darkness and reach the glowing blue star (★) to exit
- Complete all 3 levels to win!

## Features

- 🎮 3 progressively challenging levels
- 🌙 Dark, atmospheric visual style
- 📱 Mobile-friendly touch controls
- 🔊 Sound effects (toggleable)
- ⏱️ Move and time tracking
- 👁️ Fog of war - can only see near your position

## Hosting on GitHub Pages

1. Push this repo to GitHub
2. Go to Settings > Pages
3. Select "Deploy from a branch" and choose `main`
4. Your game will be live at `https://yourusername.github.io/amaze-game`

## For Kids

- Help the glowing blue orb find its way out!
- Watch out for dark walls - you can't go through them
- The star marks the exit
- Try to finish each level in as few moves as possible
